Exercise 1 Read the function

Read run and decide when you understand it.

This exercise deliberately has no solution. There is no hidden correct answer to reveal: you decide when your understanding is sufficient. Use the checklist to judge that for yourself — it tells you what to look at, never what the answer is.

Independent-reading checklist

These ticks are for you alone: nothing is checked or graded.

You do not need this course anymore. Open Ono-Sendai.

This was the last lesson. From here on, independent source reading is the activity: pick a file, read it the way you read the code in this course, and use the checklist whenever you want to test your own understanding.

Get the source with Git. The repository is https://github.com/godspeed-you/ono-sendai:

git clone https://github.com/godspeed-you/ono-sendai
cd ono-sendai
git checkout 0123456789abcdef0123456789abcdef01234567

That commit (tagged v0.1.0) is the exact revision every snippet in this course was quoted from. Newer revisions are just as readable — that is the point.
