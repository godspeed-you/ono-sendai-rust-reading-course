›Where we are

Every command in the shell produces a Value. This is the type that travels through a pipeline, so almost every other file uses it.

Methods that borrow

A method taking &self only reads the value: the caller keeps ownership. See borrowing and the glossary.

◆Why does Ono-Sendai do this?

Error messages need a short type name, which is why this method exists.
